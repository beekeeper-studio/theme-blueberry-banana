# Blueberry Banana for Beekeeper Studio

Blueberry Banana is an easy-on-the-eyes theme with a cyberpunkish feeling. A fork of the [Blueberry Banana VS Code](https://github.com/PeterShershov/blueberry-banana-vscode-theme) theme by Peter Shershov.
